# One Line, No Deadline Met

A tiny deterministic Python program that writes one single-line joke
excusing a missed deadline to `/output/entry.txt`.

## The line

> My calendar said the deadline was Friday, but my calendar also thinks it's still 2019, so really, who's the unreliable one here?

## Run

```sh
python3 main.py
```

No input, no network, no environment variables, no randomness — every run
writes the exact same line.
